How Assimilate compares with other Borg tools

Several good projects put a friendlier face on BorgBackup, and they solve different problems. This page shows where each one fits, including the things Assimilate does not do yet. Checked against each project's documentation and source in October 2026.

At a glance

Fleet control plane

Assimilate

Server and Linux agents. Schedules, monitors and restores backups on many machines; repository keys stay on the server.

Fleet control plane

Borg Backup Server

Server and agents for Linux, Windows and macOS. Stores repositories on its own disk or with hosted providers.

Repository server

BorgWarehouse

Web UI for running a central repository server: users, SSH access, quotas and health. Clients run their own backups.

Per-host CLI

borgmatic

Configuration-file wrapper around borg for one machine, with database dumps, snapshots and monitoring hooks.

Desktop app

Vorta

Graphical client for one Linux or macOS desktop, with profiles, built-in scheduling and archive browsing.

Choosing between them

Short, fair summaries. Each tool is the better choice for someone.

Assimilate vs Borg Backup Server

Choose Borg Backup Server if
you back up Windows or macOS machines, want database plugins, filesystem snapshots, S3 offsite copies, single sign-on, Prometheus metrics, or a mature release with a large user base.
Choose Assimilate if
repository keys must stay off your backup machines, including with hosted providers, or you want one schedule spanning many hosts and repositories, power management that also shuts machines down, libvirt VM backups, quota enforcement, an audit log, archive diff and an OpenAPI-described API.

Assimilate vs BorgWarehouse

Choose BorgWarehouse if
you run a repository server for other people or teams who manage their own backups, and want per-repository append-only mode, quotas, single sign-on and Apprise alerts on that server.
Choose Assimilate if
you want one place that also runs the backups: scheduling, retention, restores and monitoring of the machines themselves.

Assimilate vs borgmatic

Choose borgmatic if
you manage a few hosts as code, need database dumps and filesystem snapshots, and are happy with cron and a monitoring service instead of a dashboard.
Choose Assimilate if
you would rather see every host, schedule and archive in one UI, restore from a browser, and give other people access with roles.

Assimilate vs Vorta

Choose Vorta if
you back up your own Linux or macOS desktop and want a native app with archive mounting.
Choose Assimilate if
you look after more than one machine, including servers and machines that are usually asleep.
