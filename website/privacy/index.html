Privacy

Privacy

Short version: neither this website nor the Assimilate software collects anything about you.

This website

This site is a set of static pages hosted on GitHub Pages. It sets no cookies, runs no analytics or tracking scripts, and loads no fonts, scripts or images from third parties. GitHub, as the host, receives the usual request data such as your IP address; see the GitHub Privacy Statement.

The Assimilate software

Assimilate runs on your own hardware and talks only to the machines you connect to it. It contains no telemetry, no usage reporting and no update checks that contact the project. Your backups, passphrases and configuration never leave your infrastructure.
